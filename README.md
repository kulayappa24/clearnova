# ClearNova: Smart AI & IoT Waste Segregation & Sanitization Platform

🌐 **Live Production Application**: [https://clearnova-2026.surge.sh](https://clearnova-2026.surge.sh)

---

## 📄 Overview
ClearNova is an enterprise-grade AI and IoT platform designed for automated waste classification, real-time smart bin monitoring, vehicle route optimization, and citizen sanitization management.

## 🏗️ Architecture & Modules
- ****: React 18, TypeScript, Vite, TailwindCSS v4, Mobile Bottom Nav, SVG Logo.
- ****: Java 21, Spring Boot 3.3, REST APIs, WebSockets, Spring Integration MQTT.
- ****: FastAPI, PyTorch Edge Vision Waste Classifier.
- ****: PostgreSQL Database Schema & Mosquitto MQTT Broker.
- ****: ESP32 Firmware C++ (.ino) & Telemetry Simulator.
